# 🎧 Premium Naat Player (Auth & Persistence)

A high-performance web application designed for listening, managing, and organizing Naats with secure authentication and offline persistence.

---

## 🚀 Project Summary

Premium Naat Player is a feature-rich web application built using modern web technologies. It allows users to upload, manage, and play Naats with a personalized experience. The application runs entirely on the client side, ensuring privacy and fast performance.

---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure and layout  
- **CSS3 (Vanilla)** – Custom styling with Glassmorphism, animated gradients, Flexbox & Grid  
- **JavaScript (Vanilla)** – Core application logic without frameworks  
- **IndexedDB** – Persistent local database for storing audio files and user data  
- **Web Audio API** – Audio playback and visualizer effects  
- **RemixIcon** – Icon library for modern UI design  

---

## ✨ Key Features

- 🔐 **Authentication System** – Secure login and registration for users  
- 👥 **Multi-User Support** – Separate playlists for each user  
- 💾 **Offline Persistence** – Naats stored permanently using IndexedDB  
- 🔍 **Search & Filter System** – Quickly find naats by name or category  
- 🎵 **Advanced Audio Player** – Play, pause, loop, shuffle, and volume control  
- 📱 **Fully Responsive UI** – Optimized for mobile, tablet, and desktop  

---

## 🎨 UI / Theme

- Deep Forest Green & Gold Islamic-inspired theme  
- Clean glassmorphism design  
- Custom branding with logo and favicon support  
- Smooth animations and interactive UI elements  

---

## 🔒 Privacy & Security

- All data is stored locally in the browser (IndexedDB)  
- No server-side storage or external data tracking  
- Fully private user experience
